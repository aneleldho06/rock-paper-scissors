# 🎮 Rock Paper Scissors — Terminal Game

A simple, fun **Python** game that lets you play **Rock 🪨, Paper 📄, and Scissors ✂️** against the computer — right in your terminal.
Built just for learning and having fun with coding basics!


## 🧠 About the Project

This is a beginner-friendly project written in Python to help practice:
- Conditionals (`if`, `elif`, `else`)
- Loops and user input
- Random number generation
- Basic ASCII art display
- Simple game logic and structure

It’s a great mini-project to strengthen your logic building skills and understand how a terminal-based game works.


## ⚙️ Features

✅ Play against the computer
✅ Random computer moves
✅ Beautiful ASCII hand symbols for Rock, Paper, and Scissors
✅ Clear and fun result messages (win, lose, or draw)
✅ Beginner-friendly, 100% Python — no extra libraries needed
